¿Qué es una Zona de Activación
(Trigger Area)?
Definición: un área invisible en el espacio 3D que no bloquea el paso, pero dispara una acción cuando la cámara o entidad entra en ella.
Dos tarjetas comparativas: los 2 métodos matemáticos para calcular triggers en Three.js.
Distancia Radial
Vector3.distanceTo
Ideal para fuentes, fogatas o áreas circulares.
distancia = posicionCamara.distanceTo(centroZona)
Si distancia < radio, se activa el evento.
Cajas Delimitadoras AABB
Box3
Cajas invisibles con coordenadas mínimas y máximas (min, 
max). Ideales para puertas, portales o cuartos rectangulares.
zonaBox.containsPoint(camera.position)

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
// 1. ESCENA, CÁMARA Y RENDERIZADOR
const scene = new THREE.Scene();
// CIELO AZUL VIBRANTE Y NIEBLA ATMOSFÉRICA DE PROFUNDIDAD
scene.background = new THREE.Color(0x38bdf8); // Azul cielo veraniego brillante
scene.fog = new THREE.FogExp2(0x38bdf8, 0.015); // Niebla suave que difumina el horizonte
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000);
camera.position.set(0, 5, 15); // Elevada y alejada para ver el parque
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
// 2. CONTROLES Y LUCES
const controls = new OrbitControls(camera, renderer.domElement);
controls.target.set(0, 1, 0);
controls.update();
const luzAmbiental = new THREE.AmbientLight(0xffffff, 0.7);
scene.add(luzAmbiental);
const luzSol = new THREE.DirectionalLight(0xffffff, 1.2);
luzSol.position.set(10, 20, 10);
scene.add(luzSol);
// 3. CARGA DEL MODELO .GLB
const loader = new GLTFLoader();
loader.load('metaverso.glb', (gltf) => {
    scene.add(gltf.scene);
    console.log("¡Escenario del Parque cargado!");
});

function animate() {

    // Animación del portal
    portal.rotation.z += 0.02;

    if (posInfo) {
        posInfo.innerText = `X: ${camera.position.x.toFixed(1)} | Z: ${camera.position.z.toFixed(1)}`;

    // TRIGGER 1: Detección Radial de la Fuente
    const distancia = camera.position.distanceTo(posFuente);

    if (zonaNombre) {
        if (distancia < 5) {
            zonaNombre.innerText = "En el área de la fuente";
        } else {
            zonaNombre.innerText = "Paseando por el parque";
        }
    }

Mejora Visual (Paso 2): Creación de la Fuente de Agua
▸  Ubicación: Archivo main.js · En el bloque global de configuración, AFUERA y ANTES de la función animate() (justo debajo de la creación 
del portal y los triggers)
// =========================================================
// MEJORA 2: CREACIÓN DEL SISTEMA DE PARTÍCULAS (FUERA DE ANIMATE)
// =========================================================
const numParticulas = 250;
const geometriaAgua = new THREE.BufferGeometry();
const posicionesAgua = new Float32Array(numParticulas * 3);
const velocidadesAgua = [];
for (let i = 0; i < numParticulas; i++) {
    // Posición inicial cerca de la copa de la fuente (Y: 1.8)
    posicionesAgua[i * 3] = (Math.random() - 0.5) * 0.3;
    posicionesAgua[i * 3 + 1] = 1.8 + Math.random() * 0.5;
    posicionesAgua[i * 3 + 2] = (Math.random() - 0.5) * 0.3;
    // Impulso inicial hacia arriba y dispersión horizontal
    velocidadesAgua.push({
        x: (Math.random() - 0.5) * 0.03,
        y: 0.04 + Math.random() * 0.04,
        z: (Math.random() - 0.5) * 0.03
    });
}
geometriaAgua.setAttribute('position', new THREE.BufferAttribute(posicionesAgua, 3));
const materialAgua = new THREE.PointsMaterial({
    color: 0x7dd3fc, // Azul celeste brillante
    size: 0.15,
    transparent: true,
    opacity: 0.85
});
const chorroFuente = new THREE.Points(geometriaAgua, materialAgua);
scene.add(chorroFuente);
Explicación
¿Por qué va AFUERA de animate()? Este 
bloque construye los 250 objetos 
geométricos de las gotas una sola vez en 
memoria. Si lo pusiéramos dentro del 
bucle animate(), crearíamos miles de 
objetos nuevos por segundo hasta 
congelar el navegador.

Mejora Visual (Paso 3): Animación del Agua y 
Gravedad
▸  Ubicación: Archivo main.js · DENTRO de la función animate() (en las primeras líneas del bucle, justo después de portal.rotation.z += 
0.02;)
function animate() {
    requestAnimationFrame(animate);
    // Rotación del portal
    portal.rotation.z += 0.02;
    // =========================================================
    // MEJORA 3: ANIMACIÓN DEL AGUA Y CAÍDA DE GOTAS (DENTRO DE ANIMATE)
    // =========================================================
    const posiciones = chorroFuente.geometry.attributes.position.array;
for (let i = 0; i < numParticulas; i++) {
    // 1. Aplicar movimiento
    posiciones[i * 3] += velocidadesAgua[i].x;
    posiciones[i * 3 + 1] += velocidadesAgua[i].y;
    posiciones[i * 3 + 2] += velocidadesAgua[i].z;
    // 2. Gravedad (atrae las gotas hacia abajo)
    velocidadesAgua[i].y -= 0.0018;
    // 3. Reinicio: Si la gota cae al plato (Y < 1.0), vuelve a subir
    if (posiciones[i * 3 + 1] < 1.0) {
        posiciones[i * 3] = (Math.random() - 0.5) * 0.2;
        posiciones[i * 3 + 1] = 1.8;
        posiciones[i * 3 + 2] = (Math.random() - 0.5) * 0.2;
        velocidadesAgua[i].y = 0.04 + Math.random() * 0.04;
    }
}
// Notificar a Three.js que las posiciones cambiaron en este frame
chorroFuente.geometry.attributes.position.needsUpdate = true;
// ... (Sigue el código de HUD, Triggers y renderer.render) ...
Explicación · ¿Por qué va DENTRO de animate()? Se ejecuta 60 veces por segundo: aplica la gravedad y actualiza la posición de cada gota. 
needsUpdate = true ordena a la GPU volver a dibujar las partículas en su nueva posición.
