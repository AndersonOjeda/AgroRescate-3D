--- PAGE 5 ---
Tu Escena 3D tiene un Presupuesto Estricto
En el diseño web 3D, no gana el que hace el modelo más realista, gana el que logra la mejor ilusión óptica usando la 
menor cantidad de recursos posibles.
1
Elimina lo invisible
Si el jugador nunca va a ver la parte 
de abajo de tu mapa o el interior de 
una caja, borra esas caras en 
Blender. Son matemáticas inútiles 
que el navegador sigue calculando.
2
Cilindros y Esferas son 
peligrosos
Un cubo tiene 6 caras. Una esfera 
suave por defecto en Blender puede 
tener miles. Usa cilindros de pocos 
lados (ej. 8 o 12 caras) para simular 
árboles o columnas.
3
Colores vs. Texturas
Cargar una imagen JPG de ladrillos 
en 4K pesa muchísimo en la 
memoria RAM del navegador. Usar 
materiales de "Colores Sólidos" no 
pesa absolutamente nada.
Guia en Blender: Pídeles que activen la opción "Statistics" en Blender haciendo clic derecho en la barra inferior 
oscura. Así podrán ver en tiempo real cuántos polígonos tiene su mundo antes de cometer el error de exportarlo.

Script de Python completo
import bpy
# 1. Limpiar la escena por defecto
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.delete(use_global=False)
# --- FUNCIÓN AUXILIAR PARA CREAR MATERIALES RÁPIDO ---
def crear_material(nombre, color):
    mat = bpy.data.materials.new(name=nombre)
    mat.diffuse_color = color
    return mat
# --- DEFINIR LA PALETA DE COLORES ---
mat_pasto = crear_material("Pasto", (0.1, 0.5, 0.1, 1))
mat_piedra = crear_material("Piedra", (0.6, 0.6, 0.6, 1))
mat_agua = crear_material("Agua", (0.1, 0.4, 0.8, 1))
mat_madera = crear_material("Madera", (0.3, 0.15, 0.05, 1))
mat_hojas = crear_material("Hojas", (0.2, 0.8, 0.2, 1))
# 2. CREAR EL SUELO
bpy.ops.mesh.primitive_plane_add(size=20, location=(0, 0, 0))
bpy.context.active_object.data.materials.append(mat_pasto)
# 3. CONSTRUIR LA FUENTE CENTRAL
# Base redonda de la fuente
bpy.ops.mesh.primitive_cylinder_add(radius=3, depth=0.5, location=(0, 0, 0.25))
bpy.context.active_object.data.materials.append(mat_piedra)
# Nivel de agua de la piscina
bpy.ops.mesh.primitive_cylinder_add(radius=2.8, depth=0.5, location=(0, 0, 0.3))
bpy.context.active_object.data.materials.append(mat_agua)
# Pedestal central
bpy.ops.mesh.primitive_cylinder_add(radius=0.5, depth=2.5, location=(0, 0, 1.25))
bpy.context.active_object.data.materials.append(mat_piedra)
# Plato superior
bpy.ops.mesh.primitive_cylinder_add(radius=1.5, depth=0.3, location=(0, 0, 2.5))
bpy.context.active_object.data.materials.append(mat_piedra)
# Cúpula de agua superior (Low Poly)
bpy.ops.mesh.primitive_ico_sphere_add(subdivisions=2, radius=0.8, location=(0, 0, 2.8))
bpy.context.active_object.data.materials.append(mat_agua)
# 4. CONSTRUIR EL BORDE DE COLUMNAS (Usando bucles para automatizar)
# Columnas laterales (Eje Y)
for x in [-9, 9]:
    for y in range(-9, 10, 3):
        bpy.ops.mesh.primitive_cube_add(size=1, location=(x, y, 1))
        bpy.context.active_object.scale = (0.3, 0.3, 2) # Las hacemos altas y delgadas
        bpy.context.active_object.data.materials.append(mat_piedra)
# Columnas frontales y traseras (Eje X)
for y in [-9, 9]:
    for x in range(-6, 7, 3):
        bpy.ops.mesh.primitive_cube_add(size=1, location=(x, y, 1))
        bpy.context.active_object.scale = (0.3, 0.3, 2)
        bpy.context.active_object.data.materials.append(mat_piedra)
# 5. AGREGAR UN ÁRBOL EN UNA ESQUINA
bpy.ops.mesh.primitive_cylinder_add(radius=0.5, depth=2, location=(5, 5, 1))
bpy.context.active_object.data.materials.append(mat_madera)
bpy.ops.mesh.primitive_ico_sphere_add(subdivisions=2, radius=2, location=(5, 5, 2.5))
bpy.context.active_object.data.materials.append(mat_hojas)

Usa siempre JPG. El PNG pesa más y solo sirve si hay transparencias.

Máximo 512x512 o 1024x1024 píxeles. Pantallas pequeñas no notan más detalle, pero su batería sí.

TEXTURIZADO WEB · LABORATORIO
El Árbol de Nodos (Pestaña 
Shading)
1 Insertar Imagen: en la ventana inferior oscura, presiona Shift + A → 
Texture → Image Texture. Clic en Open y carga tu JPG de pasto.
2 Aplicar el Color: conecta el punto amarillo (Color) al punto amarillo 
(Base Color) del Principled BSDF.
3 Nodos de Escala: Shift + A → Mapping (a la izquierda) y Shift + A → 
Texture Coordinate (al inicio).
4 El Cableado: conecta el punto azul UV al primer Vector, y el Vector de 
salida al Vector morado de tu imagen.
5 Ajuste Final: en Mapping, sube Scale (X y Y) a 10 o 20. ¡La textura se 
repetirá con tamaño realista!

for mat in bpy.data.materials:
    if mat.use_nodes and mat.node_tree:
        principled = mat.node_tree.nodes.get("Principled BSDF")

            if not principled.inputs["Base Color"].is_linked:

Generando el archivo .glb
1. PASO OBLIGATORIO (Empaquetar la imagen):
Ve al menú superior: File > External Data > Pack 
Resources.
Esto inyecta la textura pasto.jpg dentro del archivo sin

Tab en modo objeto, luego presiona A en Blender: todo 
el escenario resaltado en naranja.
Ir a: File > Export > glTF 2.0 (.glb).
Configuración estricta
Opción Valor
Format glTF Binary (.glb)
Include Selected Objects (sin luces ni cámaras inútiles).
Transform +Y Up (para que el piso no quede de lado).
Data > Material Materials: Export / Images: Automatic
⚠ REGLA DE ORO DE RUTA: Nombra el archivo metaverso.glb y guárdalo en la raíz de tu carpeta del laboratorio (junto a 
index.html y main.js). Control de calidad: El archivo final debe pesar más de 300 KiB - 500 KiB. Si pesa 90 KiB, no se 
empaquetó la textura y debes hacer el paso 1 nuevamente.

Configuración del Mundo 3D (main.js - Parte 1)
Cámara, Luces y Escena. Aquí preparamos el entorno virtual donde vivirá nuestro parque. Es vital alejar la cámara para no aparecer enterrados 
en el piso. Pega esta primera parte en tu main.js:
import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
// 1. CREAR LA ESCENA
const scene = new THREE.Scene();
// 2. CONFIGURAR LA CÁMARA
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / 
window.innerHeight, 0.1, 1000);
camera.position.set(0, 5, 15); // Altura a nivel de los ojos y distancia hacia 
atrás
// 3. RENDERIZADOR
const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: 
true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
// 4. CONTROLES DE ÓRBITA (Para girar con el 
mouse)
const controls = new OrbitControls(camera, 
renderer.domElement);
controls.target.set(0, 2, 0);
controls.update();
// 5. ILUMINACIÓN
const luzAmbiental = new 
THREE.AmbientLight(0xffffff, 0.6);
scene.add(luzAmbiental);
const luzDireccional = new 
THREE.DirectionalLight(0xffffff, 1);
luzDireccional.position.set(10, 20, 10);
scene.add(luzDireccional);
