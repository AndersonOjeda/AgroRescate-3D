Fase 2: Proyección de Video como Textura 3D 
Agrega un elemento de video en memoria y conéctalo como textura a una geometría plana: 
JavaScript 
// 1. Crear elemento HTML5 de Video 
const video = document.createElement('video'); 
video.src = '/assets/video.mp4'; 
video.load(); 
video.loop = true; 
video.muted = true; // Requerido por navegador para autoplay 
video.play(); 
 
// 2. Crear VideoTexture en Three.js 
const videoTexture = new THREE.VideoTexture(video); 
 
// 3. Aplicar a una Malla 3D (Pantalla) 
const geometry = new THREE.PlaneGeometry(4, 2.25); 
const material = new THREE.MeshBasicMaterial({ map: videoTexture, side: 
THREE.DoubleSide }); 
const pantallaMesh = new THREE.Mesh(geometry, material); 
scene.add(pantallaMesh); 
Fase 3: Integración de Audio Espacial (PositionalAudio) 
Vincula el audio directamente a la posición de la pantalla 3D para que el sonido cambie 
según la distancia de la cámara: 
JavaScript 
// 1. Crear Listener y vincularlo a la cámara 
const listener = new THREE.AudioListener(); 
camera.add(listener); 
 
// 2. Crear fuente de sonido posicional 
const sound = new THREE.PositionalAudio(listener); 
 
// 3. Cargar el archivo de audio 
const audioLoader = new THREE.AudioLoader(); 
audioLoader.load('/assets/audio.mp3', function(buffer) { 
  sound.setBuffer(buffer); 
  sound.setRefDistance(1); // Distancia donde el volumen es máximo 
  sound.setMaxDistance(10); // Distancia donde el audio deja de 
escucharse 
  sound.setLoop(true); 
  sound.setVolume(0.8); 
  sound.play(); 
});

DESAFÍO Y ENTREGABLE FINAL: "ESTACIÓN MULTIMEDIA INMERSIVA" 
Consigna Creativa En lugar de presentar una simple pantalla plana flotando, los 
estudiantes deben diseñar una escena 3D temática orientada a un concepto a su elección. 
El objetivo es que la tecnología (video + audio espacial + animación) sirva a una narrativa 
visual. 
Opciones de Conceptos Sugeridos: 
• Cyberpunk Billboard: Un anuncio publicitario flotando entre edificios oscuros con 
luces neón. 
• Retro Arcade 80s: Una máquina de videojuegos clásica en una habitación oscura 
donde la pantalla reproduce el video. 
• Televisor Vintage Embrujado: Un TV de tubo catódico antiguo en medio de un 
escenario misterioso con animación distorsionada. 
• Holograma Alienígena: Una plataforma futurista que proyecta el video con 
rotaciones complejas y materiales semitransparentes. 
• Concepto Libre: El estudiante puede proponer su propio universo visual. 
Requisitos del Entregable: 
1. Entorno 3D completo: Incorporar al menos 3 objetos geométricos o modelos 
adicionales que ambienten el concepto elegido. 
2. Animación fluida: El objeto principal o elementos del entorno deben animarse en 
el bucle a 60 FPS. 
3. Interacción de Usuario: Agregar un botón u orden de teclado para iniciar/pausar la 
reproducción de video y sonido (para superar la restricción de Autoplay de los 
navegadores). 
4. Audio Espacial Funcional: Permitir al usuario mover la cámara o el objeto para 
comprobar cómo disminuye/aumenta el volumen según la posición en el espacio 
3D.
