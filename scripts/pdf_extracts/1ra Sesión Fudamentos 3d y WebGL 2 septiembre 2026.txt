¿ Computación gráfica el impacto del
Hardware ?
1. CPU (La Directora)
•Rol: Lógica, física del entorno e interacciones del usuario.
•Operación gráfica: Ejecuta el Game Loop (lee entradas,actualiza pantalla y lee
objetos) y decide qué objetos ve la cámara (Frustum Culling).
•Impacto en Software: Envía las órdenes de dibujo a la GPU (Draw Calls). Su
exceso satura la CPU.
⚙️ 2. GPU (La Fuerza Bruta)
•Rol: Procesamiento masivo de datos matemáticos en paralelo.
•Operación gráfica: Transforma las coordenadas 3D a la pantalla 2D y calcula el
color de cada píxel (Shaders).
•Impacto en Software: Procesa millones de polígonos e iluminación
simultáneamente en tiempo real.
🧠 3. Memoria (RAM vs. VRAM)
•RAM (Sistema): Almacena el código base y los archivos originales (.gltf, .png) al
cargar la aplicación.
•VRAM (Gráfica): Memoria ultra rápida en la GPU. Almacena las mallas de
vértices y texturas descomprimidas para acceso inmediato.
•Impacto en Software: La transferencia de datos (RAM ➡️ VRAM) debe
hacerse una sola vez al inicio para evitar caídas de fotogramas (FPS)


--- PAGE 6 ---
¿Qué es WebGL?
Explicación Docente: "La CPU (procesador) es como un profesor de 
matemáticas muy inteligente, pero que resuelve un problema a la vez. La 
GPU es como un ejército de 1000 niños de primaria: no saben 
matemáticas complejas, pero pueden pintar millones de píxeles al 
mismo tiempo".
Web Graphics Library. Es la tecnología que permite a tu
navegador usar la T arjetaGráfica (GPU) de tu PC para dibujar en
3D sin instalar nada extra.
WebGL es la API estándar nativa del navegador para comunicarse con la
tarjeta gráfica, pero el ecosistema se divide en tecnologías de bajo nivel
(las que hablan con el hardware) y librerías de alto nivel (los motores
que facilitan el trabajo, como Three.js).

¿Qué es Three.js?
Capa sobre WebGL: Utiliza la tecnología WebGL (Web Graphics
Library) por debajo, lo que permite usar la tarjeta gráfica (GPU) del
usuario para acelerar los gráficos sin instalar programas extra.
Conceptos de un plató de cine: Funciona de manera similar a una
escena de filmación donde configuras elementos básicos como la
escena (el espacio virtual), las cámaras (el punto de vista), las luces
(para iluminar) y los objetos o mallas con sus respectivos materiales
y texturas.
Three.js es una biblioteca o framework estándar de
JavaScript que permite crear y mostrar gráficos en 3D
directamente en el navegador web de forma sencilla


--- PAGE 9 ---
La Trinidad del 3D
Para que exista un mundo 3D, siempre necesitamos 3 cosas:
🌌 La Escena (Scene)
El universo, el espacio vacío donde existirán los 
objetos, El contenedor global (espacio 3D) donde 
conviven todos los objetos, luces y cámaras.
📷 La Cámara (Camera)
Nuestros ojos dentro de ese entorno, El punto 
de vista matemático que define la proyección 
(el paso de 3D a 2D)
🎬 El Renderizador 
(Renderer)
El motor que toma la foto de lo que ve la cámara y lo 
plasma en la pantalla plana de la computadora, El 
motor que toma la escena y la cámara para dibujar 
los píxeles en un elemento <canvas> de HTML5 a 
través de la GPU
Analogía Hollywood: Imaginen un set de grabación. Necesitas el estudio vacío (Escena), el camarógrafo (Cámara) y el 
proyector del cine (Renderizador).

Lab 2 - Escena y Renderizador
Crear archivo app.js y escribir:
// 1. Creamos el Universo (Scene)
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x111111);
// 2. Creamos el Motor de Renderizado
const renderer = new THREE.WebGLRenderer();
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
Explicación Docente: Aquí preparamos el lienzo. setSize le dice al motor que queremos 
que nuestro mundo 3D ocupe todo el ancho y alto de la ventana del navegador.


--- PAGE 16 ---
Lab 3 - Posicionando la Cámara
Continuar en app.js:
// 3. Creamos la Cámara
const camera = new THREE.PerspectiveCamera(
75,
window.innerWidth / window.innerHeight,
0.1,
1000
);
camera.position.z = 5; // Alejamos la cámara hacia nosotros
Explicación Docente: La cámara imita al ojo humano (Perspective). Inicialmente, todo 
aparece en el centro (coordenada 0,0,0). Si dejamos la cámara en el centro, ¡no veremos 
nada porque estaríamos dentro del objeto! Por eso la retrocedemos 5 pasos en el eje Z.

--- PAGE 17 ---
Lab 4 - Geometría y Material (Mesh)
Continuar en app.js:
// Creamos la forma matemática (Esqueleto)
const geometry = new THREE.BoxGeometry(1, 1, 1);
// Creamos la pintura/textura (Piel)
const material = new THREE.MeshBasicMaterial({ color: 0x00ffcc });
// Unimos Esqueleto + Piel = Malla (Mesh)
const cube = new THREE.Mesh(geometry, material);
scene.add(cube); // Lo agregamos al universo
Explicación Docente: En 3D, la forma (geometría) y el color (material) son cosas separadas. 
Juntarlas nos da un Mesh, que es el objeto real que podemos tocar y ver en nuestro mundo.

Lab 6 - Dándole Vida (Animación)
En app.js que es el panel de control de nuestro grafico vemos que el resultado del dibujo de un cuadrado fijo 
aburre. Vamos a convertirlo en un cubo 3D animado usando un bucle.
Reemplazar la línea renderer.render... por esto:
function animar() {
requestAnimationFrame(animar); // 60 veces por segundo
cube.rotation.x += 0.01; // Gira en X
cube.rotation.y += 0.01; // Gira en Y
renderer.render(scene, camera);
}
animar(); // Arranca el motor
Explicación Docente: Como en el cine, el movimiento 3D es una ilusión. Tomamos 60 fotos por 
segundo, y en cada foto, rotamos el cubo un grado. ¡Boom, tenemos animación fluida!

Lab 8 – Cambiar automaticamente la forma y animar
// debajo del bloque de set Interval
// Guardamos todas las formas en una lista
const listaDeFormas = [
new THREE.BoxGeometry(1, 1, 1), // 0: Cubo
new THREE.CylinderGeometry(1, 1, 1, 6), // 1: Hexágono
new THREE.SphereGeometry(1, 16, 16), // 2: Esfera
new THREE.TorusGeometry(0.8, 0.3, 16, 100) // 3: Dona
];
const material = new THREE.MeshBasicMaterial({ color: 0x00ffcc });
// Iniciamos con la forma 0 (Cubo)
let indice = 0;
const miObjeto = new THREE.Mesh(listaDeFormas[indice], material);
scene.add(miObjeto);
// Cambiamos la forma automáticamente cada 2 segundos
setInterval(() => {
indice = (indice + 1) % listaDeFormas.length;
miObjeto.geometry = listaDeFormas[indice]; // Actualiza el esqueleto
}, 2000);
//continua la Funcion Animar
•El Catálogo (listaDeFormas) Creamos una
lista (Array) que funciona como un "menú"
almacenando cuatro esqueletos matemáticos
diferentes (cubo, hexágono, esfera y dona).
•El Cambio Automático (setInterval): Es un
temporizador programado para ejecutarse cada
2 segundos (2000 milisegundos). Su trabajo es
avanzar al siguiente elemento de la lista y
reemplazar el esqueleto actual del objeto
(miObjeto.geometry). El uso del operador módulo
(%) es un truco matemático para que, al llegar al
final de la lista, el ciclo vuelva a empezar desde cero.
•El Motor de Vida (animar): Es un ciclo infinito
que le ordena al navegador tomar 60 "fotos" por
segundo (requestAnimationFrame). En cada foto,
el objeto gira una fracción de grado (rotation) y el
renderizador actualiza la pantalla (renderer.render).
Sin este ciclo, el objeto cambiaría de forma en la
memoria de la computadora, pero nosotros nunca
veríamos la actualización en la pantalla web.
