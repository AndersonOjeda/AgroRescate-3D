--- PAGE 4 ---
Concepto Fundamental: ¿Qué es una Malla (Mesh)?
La unión de forma y apariencia en el espacio tridimensional
GEOMETRÍA
Forma / Vértices
MATERIAL
Color / Textura
MALLA (MESH)
Objeto Visible en Escena
Definición: Un Mesh es el objeto 3D que se añade a la escena mediante scene.add(mesh).
Sintaxis Básica: const mesh = new THREE.Mesh(geometria, material);

--- PAGE 5 ---
Anatomía de la Geometría 3D
¿De qué están hechos los objetos en el pipeline gráfico?
1 Vértices (Vertices)
Puntos en el espacio tridimensional con coordenadas (x, y, z).
2 Aristas (Edges)
Líneas vectoriales que conectan dos vértices.
3 Caras (Faces / Triángulos)
Superficies planas formadas por 3 vértices.
4 Normales (Normals)
Vectores perpendiculares a la superficie que determinan cómo rebota la luz.

Código: Creando un Triángulo Personalizado
Ejemplo de creación de geometría manual con BufferAttribute
const geometry = new THREE.BufferGeometry();
// 3 vértices x 3 coordenadas (x, y, z)
const vertices = new Float32Array([
  -1.0, -1.0, 0.0,  // Vértice 1
   1.0, -1.0, 0.0,  // Vértice 2
   0.0,  1.0, 0.0   // Vértice 3
]);
geometry.setAttribute(
  'position',
  new THREE.BufferAttribute(vertices, 3)
);

Materiales PBR (Physically Based Rendering)
El estándar de la industria moderna para gráficos 3D

Material PBR estándar en Three.js

Rugosidad (roughness)
Controla el nivel de dispersión o

MeshPhysicalMaterial
Extensión del estándar con

difracción.

Transformaciones 3D: 
Posición (Position)
Desplazamiento del objeto en el espacio tridimensional
Vector3
Propiedad mesh.position que 
contiene las coordenadas x, y, z 
del objeto en la escena.
Unidades
En Three.js, 1 unidad equivale 
arbitrariamente a 1 metro en el 
mundo virtual.
Sintaxis de Desplazamiento
mesh.position.x = 2;
mesh.position.set(2, 1, -5);
mesh.position.distanceTo(camera.position);

--- PAGE 17 ---
Transformaciones 3D: Escala (Scale)
Redimensionamiento relativo de la geometría
Vector3 de Escala
Propiedad mesh.scale con 
valores por defecto (1, 1, 1).
Escala Uniforme
Cambiar todos los ejes por igual:
mesh.scale.set(2, 2, 2)
Escala No Uniforme
Deformación del objeto alterando un solo eje:
mesh.scale.y = 0.5

--- PAGE 18 ---
Transformaciones 3D: 
Rotación y Cuaterniones
Orientación angular del objeto en el espacio
1
Euler (mesh.rotation)
Rotación medida en radianes sobre ejes X, Y, Z.
2
Conversión Grados → Radianes
Radianes = Grados × (π/180).
Ej: mesh.rotation.y = Math.PI * 0.25; (45°)
3
Gimbal Lock
Problema al rotar múltiples ejes en Euler (Bloqueo de Cardán).
4
Cuaterniones (mesh.quaternion)
Representación matemática de 4 dimensiones para rotaciones 
complejas sin bloqueo.

Grupos de Objetos (THREE.Group)
Jerarquía y transformaciones compuestas
Utilidad: Permite agrupar múltiples Mesh para moverlos, rotarlos o escalarlos como 
una sola entidad.
Estructura Jerárquica: Las transformaciones del padre afectan automáticamente a 
todos los hijos.
const cocheGroup = new THREE.Group();
cocheGroup.add(chasisMesh);
cocheGroup.add(ruedaFrontalMesh);
scene.add(cocheGroup);
// Mueve todo el coche completo

import * as THREE from 'three';
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js';
import GUI from 'lil-gui';
// 1. ESCENA, CÁMARA Y RENDERIZADOR
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1e1e2e);
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
camera.position.set(0, 4, 8);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
// 2. ILUMINACIÓN (PBR)
const ambientLight = new THREE.AmbientLight(0xffffff, 0.6);
const directionalLight = new THREE.DirectionalLight(0xffffff, 1.2);
directionalLight.position.set(5, 8, 5);
scene.add(ambientLight, directionalLight);
// 3. SUELO CON CUADRÍCULA
const gridHelper = new THREE.GridHelper(12, 12, 0x888888, 0x444444);

const sphere = new THREE.Mesh(sphereGeo, sphereMat);

// Nudo Toroidal (Plástico Brillante)
const knotGeo = new THREE.TorusKnotGeometry(0.6, 0.2, 100, 16);
const knotMat = new THREE.MeshStandardMaterial({ color: 0x3498db, metalness: 0.1, roughness: 0.2 });
const knot = new THREE.Mesh(knotGeo, knotMat);
knot.position.set(0, 1.2, 0);
// Cilindro (Mate / Dieléctrico)
const cylGeo = new THREE.CylinderGeometry(0.7, 0.7, 1.5, 32);

// 6. BUCLE DE ANIMACIÓN (60 FPS)
function animate() {
  requestAnimationFrame(animate);
  sphere.rotation.x += 0.01;
  knot.rotation.y += 0.01;
  cylinder.rotation.z += 0.01;
  controls.update();
  renderer.render(scene, camera);
}
animate();
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});
